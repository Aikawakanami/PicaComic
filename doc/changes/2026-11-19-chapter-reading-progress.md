# 逐章最远阅读进度

【已实现：静态依据】阅读器用漫画源、漫画收藏 ID、章节 ID 保存逐章最远页码。每章只保留最大值，回翻和重读无需重复累加。前台可见的正文成功解码后才记录当前页，章内跳页按到达的位置计算，整章跳过不计入。沿用阅读统计的 10 秒检查点以及换章、离开前台和退出阅读时的保存路径。入口为 `lib/pages/reader/reading_logic.dart → _updateReadingActivity` 和 `lib/foundation/reading_stats.dart → ReadingSessionTracker`。

本地收藏左上角把当前目录中的逐章最远页码相加，并复用已有的整本图片数。若读完三章各 20 页且只知道这三章的页数，进度上行显示 `60`，下行显示 `/60+`。知道整本有 200 页后，下行显示 `/200`。已知目录每章都到达末页且总数相符时，绿色收藏方块用白色对号替换收藏图标，右边的蓝色方块显示图片总数。收藏标志隐藏时，蓝色总页数和对号继续并排显示。没收到逐章进度时保留原有续读信息，单独显示的图片数使用与进度上行相同的字号，过长时才缩小以放入方块。入口为 `lib/pages/favorites/local_favorites.dart → LocalFavoriteTile.readingProgressBadge` 和 `lib/components/comic_tile.dart → _ReadingHistoryPainter`。

统计库升级到版本 2，新增 `chapter_progress`。完整用户数据包仍通过 `lib/tools/io_tools.dart → exportDataToFile / importDataFromFile` 备份和恢复整个统计库。版本 1 统计库和没有统计库的旧包均兼容。新版导入同一漫画同一章节时取两边的最大页码，重复导入不重复计数。旧历史只保留已有续读位置，从之后的阅读逐步补齐章节进度。收藏夹 JSON 沿用现有统计字段，并附带该夹漫画的逐章进度。

章节身份沿用源适配器。Picacg 使用章序号，远端插章或重排后有身份错位的可能。章节在新目录中被移除时不计入当前进度；页数变短时展示累计按当前已知长度限制。
