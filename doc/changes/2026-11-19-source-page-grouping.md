# 远程列表分页合并源页

## 行为与边界

【已实现：静态依据】设置 → 浏览 → 显示 →「分页容量」可选 1X／2X／3X，默认 1X。配置键为 `lib/base.dart → Appdata.settings[93] / _Settings.browseSourcePagesPerPage`，旧设置文件缺少该键时沿用默认值。设置通过 `lib/pages/settings/explore_settings.dart → buildExploreSettings` 保存。

- 适用于使用 `ComicsPage` 的远程分页列表。以 2X 为例，应用第 1 页按顺序显示源页 1、2，第 2 页显示源页 3、4。已知源总页数时，应用页数向上取整，末页可不足指定的源页数。实际漫画数量取决于每个源页返回的结果及本地屏蔽设置。
- `lib/components/comics_list.dart → ComicsPageLogic._loadGroup` 保存成功的源页。组内遇到失败时，先前取得的条目继续显示。重试从失败的源页开始，成功后再加载本组尚未请求的源页。返回已访问页复用缓存。改合并页数会从应用第 1 页按新的边界加载。同一个列表会话内，改变合并页数及翻页都保留已选条目。
- `lib/network/eh_network/eh_gallery_page_loader.dart → EhGalleryPageLoader` 逐条跟随 EH 返回的下一页链接，支持主页、热门、搜索、网络收藏和订阅共用顺序加载。跳到尚无游标的应用页时会顺次补齐中间链接。链接失败时游标停在原链接，链接用完才确定源总页数。合并模式下，若跳页超出范围，发现末页后会回到实际末页。
- 连续模式继续使用原有 `ComicsPageLogic.loadNextPage`，本地收藏分页继续使用独立设置。远端实时增删造成的页边界变化仍可能出现，[连续模式失败跳页及来源／ID 去重](2026-11-17-continuous-loading-plan.md)另有实施计划。
